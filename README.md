
# 🔎 FindIt – Campus Lost & Found

**FindIt** is a simple, user-friendly campus Lost & Found web application designed to help students reconnect with their lost belongings and return found items to their rightful owners.

## ✨ Features

- 🏠 **Clean Dashboard** – View lost and found items at a glance.
- 🔍 **Search Items** – Search by item name, location, or description.
- 🏷️ **Category Filters** – Filter listings by categories such as Electronics, Accessories, and more.
- 📦 **Lost & Found Filters** – View lost items, found items, or all listings.
- ➕ **Report an Item** – Submit details about a lost or found item.
- 📧 **Contact Reporter** – Open Gmail to contact the person who reported an item.
- 💾 **Local Storage** – Listings remain saved in the browser after refreshing.
- 📱 **Responsive Design** – Designed to work on desktop and mobile screens.

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Lucide React
- Browser Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/niceadi69/CAMPUS_LOST_AND_FOUND.git
```

### 2. Navigate to the project folder

```bash
cd CAMPUS_LOST_AND_FOUND
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 💡 How It Works

1. Browse the available lost and found listings.
2. Search or filter to find a specific item.
3. Open a listing to view its details.
4. Contact the reporter through Gmail.
5. Submit a new listing if you have lost or found something.

## ⚠️ Note

This version uses browser Local Storage for data persistence. Listings are stored locally in the user's browser and are not automatically shared between different users or devices.

## 🎯 Project Goal

To make campus life easier by providing students with a centralized, accessible platform for reporting and recovering lost belongings.
